## 정해야 할 질문 (17개)

### 001-auth
- **A1** (FR-010) 아이디로 만든 기본 블로그 주소·닉네임이 예약 주소나 이미 쓰이는 값과 겹치면 가입을 거부할까, 숫자를 덧붙인 다른 기본값으로 만들까? (B1과 같은 질문)
- **A2** (FR-052) 탈퇴한 회원이 남의 글에 단 댓글·답글은 함께 지울까, "탈퇴한 회원" 표시로 남길까?

### 002-blog
- **B1** 기본 주소 `/@{아이디}`를 만들 수 없을 때: (a) 그런 아이디는 가입에서 막기 (b) 숫자 붙인 주소 주기 (c) 주소 변경 때 다른 회원 아이디와 같은 주소 막기
- **B2** 블로그 주소를 바꾸면 예전 주소를 다른 회원이 바로 쓸 수 있나? (a) 바로 풀기 (b) 30일 보호 (c) 변경 횟수·주기 제한
- **B3** BLOG-07 검색은 누가, 어디서, 무엇을 검색하나? (a) 주인만 마을 전체 (b) 누구나 마을 전체 (c) 누구나 그 블로그 글만

### 003-post
- **P1** (POST-06) 같은 사람이 같은 글을 다시 열면 조회수를 매번 셀까, 하루 1번만 셀까?
- **P2** (FR-016) 글을 지우면 그 글로 받은 경험치·코인을 회수할까? (GAME-05 열린 질문과 같음)
- **P3** (FR-047) 다른 글에 붙은 사진·파일을 새 글에 붙여 넣으면: (a) 다시 올림 (b) 저장 때 뺌 (c) 새 글로 옮김

### 004-social
- **S1** (FR-013) 블로그 주인과 관리자도 남의 댓글을 지울 수 있나, 작성자만인가?
- **S2** (FR-018) 없는·다른 글의·삭제된 댓글에 답글을 보내면 거부하고 문구를 보여줄까, 지금처럼 받아 줄까?

### 005-game
- **G1** (FR-020) 출석 1~7일차 보상 숫자를 제안값으로 확정할까?
- **G2** (FR-045) 공감·댓글·답글 알림을 GAME 범위에 둘까, SOC로 옮길까?

### 006-shop
- **H1** (FR-011) 이미 캐릭터를 산 회원은 계속 쓰게 둘까, 코인을 돌려주고 기본 캐릭터로 되돌릴까?
- **H2** (FR-013) 아바타 꾸미기·가구·성장 아이템의 첫 출시 목록과 가격·필요 레벨은?

### 007-town
- **T1** (FR-029) 방문자에게 보여줄 "인기 블로그" 기준: 이웃 수, 최근 30일 공감 수, 조회수 중 무엇?
- **T2** (FR-036) 즐겨찾은 이웃의 글은 전부 위로 올릴까, 최근 7일 글만 올릴까?
- **T3** (FR-059) 집은 무엇으로 성장하나: 레벨, 공개 글 수, 코인 증축?

## 원본 문서에서 고칠 곳

spec을 쓰면서 찾은, `docs/01-requirements.md` 안에서 서로 맞지 않는 부분이다. spec은 2026-10-07 결정을 따랐다.

**온보딩 흔적 (전 영역)**
- AUTH-02·05·09, BLOG-01, POST 전체, SOC 전체, SHOP-01·04·06, GAME-01~07, TOWN-01과 2장 "회원", 3장 사용자 흐름에 온보딩·`/onboarding`이 남아 있다.
- 닉네임 길이가 본문은 2~12자(`닉네임은 12자까지예요`), 결정은 2~20자.
- 가입 축하 🪙 100, 기본 카테고리 "일상"이 결정의 가입 처리 목록에 없다 (spec은 둘 다 유지).

**주소·예약어**
- 예약어 목록이 AUTH-02와 BLOG-02에서 다르고(`farm`), `attendance`·`tags`·`notice`·`wallet`·`files`가 빠져 있다. `onboarding`은 없어진 화면이다.
- BLOG-02는 "주소는 바꿀 수 없다", BLOG-03 결정은 변경 허용.
- 관리자 블로그 `/@notice`가 "주소 = 아이디" 규칙과 다르고 예약어에도 없다.

**상점·캐릭터 판매 중단(1.8) 뒤 남은 문구**
- 꾸미기 안내 `더 많은 캐릭터와 배경은 상점에서 만날 수 있어요.`, 상점 이름표 부제 `캐릭터·배경`, 레벨업 팝업 "이런 친구를 데려올 수 있어요", GAME-01 기본 흐름 3번, SHOP-02 예시(토끼).
- 상점 구역이 "세 구역"으로 되어 있어 성장 아이템 구역이 없다. 구매 성공 문구·`보유 중`이 여러 개 살 수 있는 성장 아이템과 맞지 않는다.

**출석 자동화(1.10) 뒤**
- 하루 최대 경험치 190 → 7일차 기준 210 (농장 경험치는 계산에 없음).
- 출석 화면 문구 `연속 출석이 끊겼어요`, `오늘은 이미 출석했어요` 등과 광장 출석 도장 "(보상 받기 🎁)"는 자동 출석에서 보일 일이 없다.

**첨부·프로필**
- POST-07: 결정은 "붙여 넣으면 다시 올린다", 예외 흐름과 에디터는 그대로 둔다 (P3).
- TOWN-10 "프로필 사진 올리기가 없다"가 프로필 사진 결정과 충돌.
- 전시 동물 위치: 결정은 "블로그(미니룸 옆)", TOWN-09 수용 기준은 "프로필".

**기타**
- `docs/02-erd.md`를 여러 곳에서 가리키지만 저장소에 없다.
- 요약 표 상태가 ✅인데 결정 뒤 미구현: SHOP-01, GAME-04, SOC-02, TOWN-04(8채 → 10채).
- 동시 공감 때 오류 화면(SOC-03), 영어 오류 문구(SOC-01·02, POST)가 NF-15·NF-19와 어긋난다.
- 글 수 표시가 화면마다 공개 글만/비공개 포함으로 다르다 (BLOG·POST-02).
- 정화 허용 태그에 `h1`이 있지만 에디터는 H2·H3만 쓴다.
- 프레임 기준 TOWN-05 50fps vs NF-20 60fps. TOWN-06은 W인데 ❌.
- `/feed` 이름이 "마을 최신 글"과 "마을 소식"으로 섞여 있다.
